# Physics-laboratory — «Ғылым Ордасы» физика платформасы

Физика пәніне арналған қазақ тіліндегі оқу платформасы (7–11 сыныптар). Мұғалімдер мен оқушыларға арналған материалдар,
формулалар, ойындар, интерактивті симуляциялар, виртуалды зертханалар және PISA · ББЖМ · ҰБТ-ға дайындық бір сайтта.

## Рөлдер және тіркелу

- **Әкімшілер — ең көбі 4 адам** (платформа иесі + 3 көмекші). Олар тіркелу арқылы ашылмайды:
  иесі `ADMIN_LOGIN` / `ADMIN_PASSWORD` айнымалыларынан бірінші іске қосуда жасалады, ал көмекшілерді тек иесі
  «Әкімші → Әкімшілер» бөлімінде қосады.
- **Мұғалім** өзі тіркеледі (мектепті таңдайды немесе жаңасын ұсынады), әкімші растағанша сынып аша алмайды және материал жүктей алмайды.
- **Оқушы** мұғалім берген 6 таңбалы **сынып кодымен** тіркеледі: аты-жөні, логин, құпиясөз. Электрондық пошта мен телефон сұралмайды.
  Құпиясөзін ұмытса, мұғалімі уақытша құпиясөз береді (кірген соң жаңасын қоюға міндетті).

## Ең оңай жол: Render, бір батырма (ұсынылады)

1. Төмендегі батырманы басып, **GitHub арқылы** кіріңіз:

   [![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/kerim-kz/Physics-laboratory)

2. Үш өрісті толтырыңыз: `ADMIN_LOGIN` (латынша логин), `ADMIN_PASSWORD` (кемінде 10 таңба), `ADMIN_NAME` (аты-жөніңіз).
3. **Deploy Blueprint** басыңыз. Render сайтты да, дерекқорды да өзі жасайды; 5–10 минуттан кейін сайт
   `https://gylym-ordasy.onrender.com` (немесе Render берген ұқсас) мекенжайда ашылады.

Тегін деңгейдің шектеулері:
- 15 минут ешкім кірмесе, сайт «ұйықтайды» — келесі ашылуы ~1 минутқа созылады;
- бір файл 20 МБ-тан аспауы керек; файлдар дерекқорда сақталады (`FILE_STORAGE=db`);
- **тегін Render дерекқоры 30 күн жұмыс істейді**: сосын оны Render-де ақылы жоспарға ауыстыру керек
  (айына шамамен $6–7, бір батырма), әйтпесе 14 күннен кейін деректер өшеді. Тегін балама — Neon:
  [neon.com](https://neon.com)-да жоба ашып, оның қосылу жолын сайт сервисінің `DATABASE_URL` айнымалысына қойыңыз
  (Render → gylym-ordasy → Environment). Бұл жағдайда деректерді Neon-ға көшіру керек болады, сондықтан
  оны 30 күн толмай тұрып шешкен дұрыс.

## Railway-ға орналастыру

1. [railway.com](https://railway.com) → **New Project → Deploy from GitHub repo** → `kerim-kz/physics-laboratory` репозиторийін таңдаңыз.
2. Жобаның ішінде **+ New → Database → PostgreSQL** қосыңыз.
3. Қосымша сервисінің **Variables** бөліміне мыналарды енгізіңіз:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`
   - `ADMIN_LOGIN` — сіздің логиніңіз (латынша, мысалы `kerim`)
   - `ADMIN_PASSWORD` — кемінде 10 таңбалы құпиясөз
   - `ADMIN_NAME` — аты-жөніңіз
   - `NODE_ENV` = `production`
   - `UPLOAD_DIR` = `/data/uploads`
   Railway-дің тегін «Limited Trial» деңгейі (GitHub аккаунты расталмаса) сайттың кодын жарияламайды —
   онда Hobby жоспарына көшу керек немесе жоғарыдағы Render + Neon жолын қолданыңыз.
4. Сервиске **Volume** қосып, оны `/data` жолына бекітіңіз — жүктелген PPT, Word, PDF файлдары сонда сақталады.
5. **Settings → Networking → Generate Domain** — сайт `https://<атауы>.up.railway.app` мекенжайында ашылады.
   Өз доменіңізді (мысалы, `fizika.kz`) кейін осы жерден қосасыз.
6. Сайтқа `ADMIN_LOGIN` арқылы кіріп, **Әкімші → Баптаулар** бөлімінде төлем деректемелерін, байланыс пен хабарландыруды толтырыңыз,
   **Мектептер** бөлімінде алғашқы мектептерді қосыңыз.

Railway сервистің денсаулығын `/healthz` арқылы тексереді (`railway.json`). Дерекқор кестелері әр іске қосылғанда
миграциялар арқылы өздігінен жасалады.

> **Дербес деректер туралы.** Қазақстан заңы азаматтардың дербес деректерін ел ішіндегі серверде сақтауды талап етеді, ал Railway
> серверлері шетелде. Тәуекелді азайту үшін платформа тек аты-жөні, логин, мектеп пен сыныпты сақтайды (ЖСН, телефон, пошта жоқ).
> Платформа ресми түрде кеңінен қолданыла бастаса, қазақстандық хостингке көшіріңіз: код кез келген Node.js + PostgreSQL серверінде жұмыс істейді.

## Өз компьютеріңізде іске қосу

Қажет: Node.js 20.18+ (ұсынылады 22) және PostgreSQL 14+.

```bash
npm install
```

```bash
DATABASE_URL=postgres://postgres@localhost:5432/fizika ADMIN_LOGIN=owner ADMIN_PASSWORD=owner-pass-123 npm start
```

Сайт `http://localhost:3000` мекенжайында ашылады. Барлық айнымалылардың сипаттамасы — `.env.example` файлында.

## Тесттер

Тесттер бөлек бос PostgreSQL базасында жүреді (база әр іске қосқанда тазаланады):

```bash
TEST_DATABASE_URL=postgres://postgres@localhost:5432/fizika_test npm test
```

## Қауіпсіздік

Құпиясөздер scrypt арқылы хэштеледі; сессия cookie `httpOnly` және `SameSite=Lax`, ал базада тек белгінің хэші сақталады.
Барлық POST сұранымдары CSRF белгісімен тексеріледі; кіру әрекеттері шектеледі; CSP тек өз сайттың скриптеріне рұқсат береді.
Файлдар кездейсоқ атаумен сақталып, тек рұқсаты бар пайдаланушыға `attachment` ретінде беріледі; рұқсат етілген түрлер тізімі бар.
Зертхана беттері өз CSP-імен беріледі: тек олардың ішкі скриптінің SHA-256 хэшіне және Google Fonts-қа рұқсат бар.

## Зертханалар қалай жұмыс істейді

Әр зертхана (`labs/<key>.html`) артефакт ретінде жасалған және `window.claude.use('user' | 'db' | 'downloads')` арқылы жұмыс істейді.
Платформа зертхананың кодын өзгертпей, оның алдына `public/js/lab-runtime.js` үйлесімді қабатын қосады:
`subs/{uid}` құжаттары `/api/labs/<key>/subs/...` арқылы `lab_subs` кестесіне жазылады, оқушының аты-жөні мен сыныбы аккаунттан алынады,
ал нәтиже оның сынып мұғалімінің журналына (`lab_results`, дереккөзі «платформа») түседі. Мұғалім мен әкімші зертхана ішіндегі
мұғалім панелін ашады (тек өз оқушылары; әкімші — барлығы) және нәтижені өшіріп, қайта тапсыруға рұқсат бере алады.

Зертхананы жаңарту үшін артефактінің жаңа HTML нұсқасын `labs/<key>.html` файлына ауыстырыңыз — CSP хэші іске қосылғанда өздігінен есептеледі.
