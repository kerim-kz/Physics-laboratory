# Архитектура және шешімдер

## Мақсат

Физика мұғалімдері мен оқушыларына арналған бір платформа: материалдар кітапханасы (ақылы бөлімімен), формулалар
және оларды жаттау ойындары, симуляциялар, виртуалды зертханалар, PISA · ББЖМ · ҰБТ-ға дайындық. «Ғылым Ордасы»
артефактісінің физика бөлігі және оның дизайны жеке сайтқа көшірілді.

## Негізгі шешімдер

| Сұрақ | Шешім | Себебі |
|---|---|---|
| Хостинг | Railway: Node.js сервисі + PostgreSQL + Volume (файлдар) | Серверді басқару қажет емес, GitHub-тан өздігінен жаңарады |
| Стек | Express, `pg`, серверде салынатын HTML, Canvas-тағы ванильді JS | Құрастыру (build) қадамы жоқ, әлсіз мектеп құрылғыларында жылдам ашылады |
| Формулалар | KaTeX серверде салынады, ойындарда браузерде | Бет JavaScript-сіз де оқылады; CDN жоқ |
| Тіркелу | Оқушы — сынып коды; мұғалім — әкімші растауы; әкімшілер — тек иесі қосады (≤ 4) | Бөгде аккаунттарсыз, мұғалім өз сыныбын ғана көреді |
| Дербес деректер | Тек аты-жөні, логин, мектеп, сынып | Кәмелетке толмағандардың деректерін барынша аз жинау |
| Төлем | Өтінім + әкімшінің қолмен растауы | Kaspi Pay сияқты API заңды тұлғаны талап етеді; кейін қосуға болады |
| Тест банкі | Авторлық тапсырмалар, ресми форматқа ұқсас | ҰТО-ның ресми тапсырмаларын көшіру авторлық құқықты бұзады |
| Зертханалар | 16 артефакт-зертхана өзгеріссіз `labs/` ішінде, `window.claude` үйлесімді қабаты арқылы платформаның API-іне қосылған | Зертханалардың күрделі логикасын қайта жазбай, нәтижені журналға автоматты түсіру; бұрынғы кодтар да жарамды |

## Деректер моделі

`schools` → `users` (role: admin | teacher | student) → `classes` (join_code) ;
`materials` → `orders` ; `game_scores` ; `exam_units` → `exam_questions` ; `exam_attempts` ;
`lab_subs` (платформада тапсырылған зертхана жұмыстары) → `lab_results` (мұғалімнің журналы) ; `sessions` ; `settings`.

## Қауіпсіздік шекаралары

- Рұқсаттар серверде тексеріледі: `requireUser`, `requireActiveTeacher`, `requireAdmin`, `requireOwner`.
- Мұғалім тек өз сыныптары мен оқушыларын басқарады; әкімші платформа иесін өзгерте алмайды.
- Ақылы файлды тек автор, әкімші немесе төлемі расталған пайдаланушы жүктей алады.
- Тест жауаптары браузерге жіберілмейді — бағалау серверде.
- Зертхана балы браузерде есептеледі (артефактідегідей), сондықтан ол «сенім негізіндегі» нәтиже: оқушы өз аккаунтынан ғана тапсыра алады, бөгде нәтижені оқи да, өзгерте де алмайды, ал өз нәтижесін өшіре алмайды (тек мұғалім).

## Келесі қадамдар

1. Онлайн төлем (Kaspi Pay / CloudPayments) — заңды тұлға тіркелгеннен кейін.
2. Тест банкін толықтыру және мұғалімнің өз сыныбына тест тағайындауы.
3. Қазақстандық хостингке көшу (платформа ресми қолданысқа енгенде).

## 2-нұсқа (2026 ж. қараша)

- **Навигация.** Жоғарғы көлденең мәзір бүйір мәзірге (`#drawer`) ауыстырылды: `layout.js` топтап шығарады, `app.js` ашады/жабады (Esc, фон, фокус ұстау). JavaScript өшірулі болса, `<noscript>` ішіндегі қарапайым сілтемелер көрінеді.
- **Басты бет.** `public/js/hero.js` — дербес Canvas моделі (жұлдыздар ғана тартады, жылдамдықты Верле әдісі, тұрақты қадам). Экраннан тыс немесе бет жасырын болғанда есептеу тоқтайды, `prefers-reduced-motion` кезінде өздігінен басталмайды.
- **Формулалар.** Анықтамалар `src/data/formula-defs.js`-те атау бойынша сақталады. `/formulas/:id` — жеке бет, `?part=1` — терезеге арналған HTML үзіндісі (KaTeX серверде салынады). `public/js/formulas.js` терезені `<dialog>` арқылы ашады, ал JS жоқ болса, сілтеме жеке бетке апарады.
- **Олимпиада.** `src/data/olympiad.js`: мәтіндегі `$...$` және `$$...$$` `lib/tex.js` ішіндегі `texText()` арқылы экрандалып, KaTeX-пен салынады.
- **Тест банкі.** `src/data/questions-v2.js` жаңа `seed_key`-лермен қосылды — бар деректер өзгермейді, жаңа блоктар іске қосылғанда өздігінен енгізіледі. Нұсқалардың көрсетілу реті клиентте араласады, бағалау бастапқы индекс бойынша жүреді.
