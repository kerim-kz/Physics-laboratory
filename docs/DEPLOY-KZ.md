# Сайтты Қазақстандағы серверге көшіру (gylymordasy.com.kz)

Бұл нұсқаулық Ғылым Ордасын Render-ден hoster.kz-тегі VPS серверіне көшіріп, `gylymordasy.com.kz` доменімен ашуды қадамдап түсіндіреді. Командаларды көшіріп, сервердің терминаліне қою жеткілікті.

> **Құпия деректер.** Құпиясөздерді, кілттерді, Render дерекқорының мекенжайын ешкімге жібермеңіз және чатқа жазбаңыз — оларды тек серверде, скрипт сұрағанда енгізесіз.

## 0. Не керек

| Не | Қайдан |
| --- | --- |
| Домен `gylymordasy.com.kz` | hoster.kz (алынды) |
| VPS сервер: Ubuntu 24.04, 2 ГБ жады, 20–40 ГБ диск | hoster.kz → VPS |
| GitHub-қа кіру | github.com, `kerim-kz/Physics-laboratory` репозиторийі |
| Render-ге кіру | dashboard.render.com |

## 1. VPS серверін алу

1. hoster.kz-те VPS тапсырыс беріңіз: операциялық жүйе — **Ubuntu 24.04**, жады — **2 ГБ**.
2. Сервер дайын болғанда хатта немесе жеке кабинетте мыналар келеді: **IP мекенжайы** (мысалы `185.xx.xx.xx`) және **root құпиясөзі**.

## 2. Доменді серверге бағыттау (DNS)

hoster.kz жеке кабинеті → Домендер → `gylymordasy.com.kz` → **DNS жазбалары**:

| Түрі | Аты | Мәні |
| --- | --- | --- |
| A | `@` (немесе бос) | сервердің IP мекенжайы |
| A | `www` | сервердің IP мекенжайы |

Бұрыннан тұрған басқа `A` және `AAAA` жазбалары болса (тұрақ беттері), оларды өшіріңіз. Өзгеріс 15 минуттан бірнеше сағатқа дейін таралады.

## 3. Серверге қосылу

Windows-та **PowerShell**-ді, Mac-та **Терминалды** ашып:

```
ssh root@СЕРВЕРДІҢ_IP
```

Алғаш қосылғанда `yes` деп жазыңыз, сосын root құпиясөзін енгізіңіз (терезеде көрінбейді — бұл қалыпты).

## 4. Сайт кодын алу

Серверде мына командаларды кезекпен орындаңыз:

```
apt-get update && apt-get install -y git
```

```
ssh-keygen -t ed25519 -N "" -C gylym-server -f /root/.ssh/gylym_deploy
```

```
cat /root/.ssh/gylym_deploy.pub
```

Шыққан бір жолды (`ssh-ed25519 ...` деп басталады) көшіріңіз де, GitHub-та қосыңыз:
**Physics-laboratory репозиторийі → Settings → Deploy keys → Add deploy key**. Атауы: `gylym-server`. «Allow write access» белгісін **қоймаңыз**. Сақтаңыз.

Содан кейін серверде:

```
GIT_SSH_COMMAND="ssh -i /root/.ssh/gylym_deploy -o StrictHostKeyChecking=accept-new" git clone git@github.com:kerim-kz/Physics-laboratory.git /opt/gylym
```

## 5. Орнату

```
bash /opt/gylym/deploy/install.sh
```

Скрипт мыналарды сұрайды:
- **Домен** — Enter басыңыз (`gylymordasy.com.kz`);
- **Платформа иесінің логині мен құпиясөзі** — Render-дегімен бірдей енгізіңіз;
- **Аты-жөні**.

Скрипт өзі: Docker орнатады, брандмауэрді баптайды, сайтты іске қосады, HTTPS сертификатын алады және түнгі 03:30-да резервтік көшірме алуды қосады. Алғашқы іске қосу 3–5 минут алады.

Тексеру: браузерде `https://gylymordasy.com.kz` ашыңыз. Бұл кезде сайт бос (тек тапсырмалар банкі бар) — деректер келесі қадамда көшіріледі.

> DNS әлі таралмаған болса, HTTPS сертификаты алынбай тұруы мүмкін. 30 минут күтіп, `cd /opt/gylym/deploy && docker compose restart caddy` орындаңыз.

## 6. Render-дегі деректерді көшіру

1. Render → **gylym-ordasy-db** дерекқоры → **Connect** → **External** қойындысы → **External Database URL** мекенжайын көшіріңіз.
2. Серверде:

```
bash /opt/gylym/deploy/restore-from-render.sh
```

Мекенжайды сұрағанда қойыңыз (экранда көрінбейді), сосын `иә` деп жазыңыз. Скрипт пайдаланушыларды, нәтижелерді, сыныптарды, материалдар мен жүктелген файлдарды түгел көшіреді.

3. `https://gylymordasy.com.kz` сайтына Render-дегі логин-құпиясөзбен кіріп, кабинеттер мен материалдарды тексеріңіз.

## 7. Render-ді өшіру

Жаңа сайтта бәрі дұрыс екеніне көз жеткізгеннен кейін (бір-екі күн тексерген жөн):
- Render-де сайттың **Settings → Suspend** (немесе Delete) және дерекқорды өшіріңіз;
- оқушылар мен мұғалімдерге жаңа мекенжайды хабарлаңыз.

Бұл аралықта Render-де ешкім тіркелмесін немесе тест тапсырмасын: көшіргеннен кейінгі жаңа деректер Render-де қалып қояды.

## Күнделікті жұмыс

| Не істеу керек | Команда (серверде) |
| --- | --- |
| Сайтты соңғы нұсқаға жаңарту (Render-дегі Manual Deploy орнына) | `bash /opt/gylym/deploy/update.sh` |
| Сайттың күйін көру | `cd /opt/gylym/deploy && docker compose ps` |
| Қателерді көру | `cd /opt/gylym/deploy && docker compose logs --tail=100 app` |
| Резервтік көшірмені қолмен алу | `bash /opt/gylym/deploy/backup.sh` |
| Резервтік көшірмелер тізімі | `ls -lh /opt/gylym-backups` |
| ЖИ кілтін немесе басқа баптауды өзгерту | `nano /opt/gylym/deploy/.env`, сосын `cd /opt/gylym/deploy && docker compose up -d` |

`update.sh` жаңартар алдында өзі резервтік көшірме алады.

**Резервтік көшірмені компьютерге жүктеп алу** (айына бір рет ұсынылады). Өз компьютеріңізде:

```
scp root@СЕРВЕРДІҢ_IP:/opt/gylym-backups/*.sql.gz .
```

## Ақаулар

| Белгі | Не істеу керек |
| --- | --- |
| Сайт ашылмайды | `docker compose ps` — үш контейнер де `Up` болуы керек. Болмаса: `docker compose up -d` |
| «Сертификат қатесі» | DNS IP-ге бағытталғанын тексеріңіз, сосын `docker compose restart caddy` |
| Жаңартудан кейін қате | `docker compose logs --tail=100 app` нәтижесін көшіріп, әзірлеушіге жіберіңіз (құпиясөздерсіз) |
| Диск толып қалды | `docker system prune -af` (ескі бейнелерді өшіреді, деректерге тимейді) |

## Техникалық сипаттама

- `Dockerfile` — Node 22 негізіндегі сайт бейнесі.
- `deploy/docker-compose.yml` — үш қызмет: `app` (сайт), `db` (PostgreSQL 17, деректер `pgdata` томында), `caddy` (HTTPS, `www` → негізгі доменге бағыттау).
- Файлдар дерекқорда сақталады (`FILE_STORAGE=db`), сондықтан бір резервтік көшірме бәрін қамтиды.
- Сервер Қазақстанда болғандықтан, .kz аймағының талабы мен дербес деректерді Қазақстанда сақтау талабы орындалады.
